One dad joke, written to `/output/entry.txt` by `main.py` — the entry for the
[Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty on make.fun.

> I told the kids the dishwasher is the most honest appliance in the house. It always comes clean.

The joke was chosen from 24 original candidates through an internal pairwise
tournament judged on the bounty judge's own criteria: a dad joke a father
would tell at the table, a pun that lands cleanly on the first read, fresh
but inside the dad joke tradition, tight with the punchline at the end, and
natural read aloud. 96 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke deterministically
to `entry.txt` in the output directory — the same bytes on every run, no
network, no third-party packages.
